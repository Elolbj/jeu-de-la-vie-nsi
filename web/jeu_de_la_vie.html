À propos

Version web du projet POO de Terminale NSI. Les classes Python Cellule (attribut Etat), Regle, Jdlv (grille, tour, start()) et Jdlv_IHM sont traduites en JavaScript avec les mêmes noms. Au clavier : Espace, Entrée, Retour arrière.
